## Calculation Logic

### Tax Calculation (per line)
```
resolved_rate = GSTEngine.resolve_gst_rate(db, tenant_id, line.gst_rate)
line_subtotal = (quantity × rate) - discount
if is_gst_inclusive:
    line_subtotal = line_subtotal / (1 + resolved_rate / 100)
tax_split = GSTEngine.calculate_tax(origin, pos, line_subtotal, resolved_rate)
```

### Header Totals
```
discount_amount = subtotal × discount_rate / 100
adjusted_subtotal = subtotal - discount_amount
tax_proportion = adjusted_subtotal / subtotal
final_cgst = cgst × tax_proportion
... (same for sgst, igst, cess)
raw_total = adjusted_subtotal + taxes + shipping
rounded_total = round(raw_total)
round_off = rounded_total - raw_total
```

### TDS/TCS (post-flush)
```
tds_amount = rounded_total × tds_rate / 100
tcs_amount = rounded_total × tcs_rate / 100
```
